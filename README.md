# Sprite Exercise
This is a starter project for learning about MonoGame Game Services and Components  

The accompanying video tutorial can be found at [https://youtu.be/9jNldWQHM4Q](https://youtu.be/9jNldWQHM4Q)

This repository and associated video were created for the CIS 580 - Foundations of Game Programming course offered by the Department of Computer Science at Kansas State University.
